#  Registration Wizard 

A responsive multi-step Registration Wizard developed as part of the **Prodesk IT Software Developer Internship – Sprint 7**.

##  Project Overview

The Registration Wizard provides a simple and user-friendly interface for collecting user registration information through multiple steps.

The project focuses on creating a structured, responsive, and easy-to-use registration experience with proper form validation and navigation.

##  Features

- Multi-step registration form
- Step-by-step navigation
- Next and Previous buttons
- Form validation
- Required field validation
- User-friendly error messages
- Registration progress indication
- Final review before submission
- Responsive design
- Clean and modern user interface
- Mobile-friendly layout

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Git
- GitHub
